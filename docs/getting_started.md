# Getting started 

!!! warning
    When starting the application you won't see a model of a cuneiform tablet at first. This is because it takes some time to load. During loading entering inputs and pressing buttons is not possible. 

## Overview

The application is made up of three parts: 

* main screen in the middle displaying the cuneiform tablet
* editing menu on the left
* information menu on the right

Before you are able to see the editing menu you have to enter your credentials on the left side of the screen. The inputs you enter here will appear in the exported annotation file.

![](../images_compressed/getting_started_overview_smaller.png)

*Figure 1: the three components of the application*

### Main screen

On the **main screen** you can use the computer mouse to 

* select annotations (left mouse button; short press while hovering over an annotation)
* move cuneiform tablet (right mouse button; keep it pressed while hovering over cuneiform tablet and move the mouse)
* rotate cuneiform tablet (middle mouse button; keep it pressed while hovering over cuneiform tablet and move the mouse)

### Editing menu

On the **editing menu** you can 

* see the content of an annotation 
* import and export cuneiform tablets, annotations and transliteration (see [Import/Export](./editing_menu.md#import/export))
* create annotations in the form of boxes (s. [Create new annotation (box)](./editing_menu.md#create-new-annotation-box))
* create annotations in the form of polygons (s. [Create new annotation (polygon)](./editing_menu.md#create-new-annotation-polygon))
* edit the content of an annotation (s. [Edit annotation content](./editing_menu.md#edit-annotation-content))
* edit the form of an annotation (s. [Edit annotation form](./editing_menu.md#edit-annotation-form))

!!! info

### Information menu

On the **information menu** you can 

* see the content of the loaded transliteration file

!!! info
    The transliteration shown on the information menu is loaded from an external file. It's not connected to the annotations displayed on the screen. Its content doesn't change when the content of the annotations is changed in the annotator. 

* turn cuneiform tablet upside down (not possible with the mouse)
* turn cuneiform tablet back to its original orientation and position 

## Rotating the model

The model of the cuneiform tablet can be rotated in 3 ways:

* with the middle button of the computer mouse (hover over the model and keep it pressed while moving the mouse)
* with the 2 buttons on the information menu (s. [here](#information-menu))
* with keyboard shortcuts (in any direction, either by 5 oder 90°)

!!! info
    For the shortcuts to work the last mouse action must have occured on the main screen. If shortcuts shouldn't work mouse the over to the main screen and press some button.

!!! bug
    Some shortcuts (especially v, b and n) don't work in some circumstances yet.
