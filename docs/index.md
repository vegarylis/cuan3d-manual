# Cuan3D manual

This is the manual for Cuan3D.

Cuan3D is a software to annotate cuneiform tablets in 3D. It is possible to load 3D models of cuneiform tablets from .ply files, load annotations from JSON files, change the content and/or form of existing annotations, create new ones and/or export annotations as JSON files. Annotations can either be shown and drawn as boxes or polygons.

The application was created as part of a project in the study programme "Digital Methods in the Humanities and Cultural Studies" at Mainz University of Applied Sciences and Johannes Gutenberg University. It is attached to the project "Digital editing of the cuneiform texts from Haft Tappeh" of i3mainz, a research institute at Mainz University of Applied Sciences.

!!! warning
    Since the prototype was developed as part of a now concluded project, it will not be developed further. Bugs will not be fixed.

In this manual you will find some information and examples to help with using Cuan3D.
